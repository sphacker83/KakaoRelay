            옵시디언 보관함
            
      
            봇이 읽을 노트가 있는 폴더를 선택하세요. 같은 폴더를 여러 봇과 공유할 수 있습니다.
            
      
      
            
      
      
            
      
            관련 노트 발췌는 답변 생성 시 선택된 AI 서비스에 전달됩니다. 수정·삭제는 다음 질문부터 반영됩니다.
            
      
            
      
            옵시디언 · 백업
            
      
      
            봇은 옵시디언이 꺼져 있어도 노트를 읽습니다. GitHub 백업을 설정한 보관함은 옵시디언을 켜 두면 설정한 주기에 따라 백업됩니다.
            
      
            대화를 계속 지식으로 쌓으려면 ‘대화 자동 정리’ 탭에서 방과 주기를 설정하세요. 이전 대화는 AI 챗봇 → 대화분석 → 요약을 노트로 저장으로 추가할 수 있습니다.
