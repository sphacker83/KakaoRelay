# 단일 제어방 구현계획

## 목적
앱에서 지정한 일반 1:1 채팅방 하나에서 허용된 상대방이 릴레이를 관리한다. 자동답장을 중지해도 제어방 폴링은 유지한다. 기본값은 비활성화이며 관리 방과 상대방은 앱에서만 지정한다.

## 구성
1. 로컬 DB의 방 유형·직접 대화 상대 ID를 읽어 일반 1:1 방만 선택할 수 있게 한다. 이름이 아닌 프로필/방 ID/상대 ID를 검증한다.
2. 앱의 제어방 탭에 단일 방, 자연어 해석, 기능별 허용, 적용/중지, 처리 이력을 둔다. 인증/경로/제어방 설정은 채팅 명령으로 바꿀 수 없다.
3. 자동답장과 독립된 폴러가 새 텍스트만 읽는다. 최초 활성화 시 기준점을 저장한다. 삭제/첨부/다른 발신자/과거 메시지는 명령으로 실행하지 않는다. 제어방에는 일반 자동답장을 중복 실행하지 않는다.
4. 슬래시 명령은 결정적 파서, 자연어는 AI가 제한된 JSON 명령으로 변환한다. AI에 셸이나 설정 쓰기 도구를 주지 않는다. 모호한 대상과 미지원 명령은 실행하지 않는다. 자연어 변경은 구체적인 미리보기와 5분 유효 확인번호를 반환하고 확인 후 실행한다.
5. 허용 작업: 상태/도움말, 자동답장 방별 시작·중지/전체 중지, 답변방식, 페르소나 연결, 지식 축적 방 추가·제외/주기/지금 정리, 기존 정리전달 규칙의 사용 여부·주기, 앱에 등록된 프로바이더 선택. 새 전달 경로·로그인·삭제·임의 실행은 앱 전용이다.
6. 실행은 공용 서비스와 실제 자동답장 런타임을 호출한다. 설정 저장과 화면 반영을 함께 수행하며 실행 중인 다른 방은 재시작하지 않는다.
7. 처리 ID/상태/변경 전후를 로컬에 기록한다. 실행 전 소비 기록으로 중복 실행을 막으며 중단된 실행은 불확실로 남긴다. 회신은 공용 발송 대기열과 고정 요청 ID를 사용하고 결과 불명확 시 자동 재발송하지 않는다.

## 검증·배포
- 방/발신자 인증, 기능별 허용, 중복 메시지, 초기 기준점, 모호한 방, 잘못된 설정값, 확인 만료/설정 변경, 실행 실패, 중지 후 제어 유지 테스트.
- 기존 회귀 검사 및 Windows 게시 빌드. 실제 개인 대화를 테스트 명령으로 실행하지 않는다.
- 배포 전 가동 상태를 확인하고 실행 앱 교체 후 기존 감시를 복원한다. 제어방은 앱에서 명시적으로 지정하기 전에는 켜지 않는다.

## 진행
- 계획 작성 완료. 기존 기능과 저장 구조 조사 완료.

- 방별 독립 자동답장 런타임 및 인증된 GET /v1/ai/runtime 추가.
- 전체 회귀 417개 통과 후 추가·보강된 제어방 검사 25개 통과.
- 실제 로컬 DB에서 일반 1:1 방과 상대방 검증, 잘못된 상대 차단 확인.
- Windows 게시 빌드 및 앱 교체 완료. 읽기 전용 UI 바인딩 오류를 수정하고 실앱 화면 확인.
- 기존 3개 자동답장 방 재개, API에서 activeRooms=3 및 마지막 폴링 시각 확인.
- 제어방은 비활성화 상태로 배포. 실제 방 지정과 실채팅 명령 왕복은 사용자 지정 후 확인해야 함.

## 제어방 일반 대화 (2026-11-05)
- 슬래시 명령은 기존 명령 처리로 전달한다. 자연어 관리 명령의 변경 미리보기·확인 절차도 유지한다.
- 관리 명령이 아닌 텍스트는 해당 방에 연결된 페르소나와 대화 문맥으로 답한다. 별도 자동답장 세션은 실행하지 않아 중복 답장을 방지한다.
- 자연어 명령 해석을 꺼도 일반 대화와 슬래시 명령은 사용할 수 있다. 일반 대화는 설정 변경 권한이 없으며 대기 중 확인번호를 유지한다.
- 일반 대화 회신도 기존 발신자·수신방 검증, 처리 이력, 중복 전송 방지를 적용한다.

## 일반 대화 경로 통합
제어방의 비명령 메시지는 AutoReplySession.ReplyToAsync를 사용한다. 일반 자동답장과 동일한 페르소나·지식 검색·첨부 판독·감정 이미지·이미지 생성·백그라운드 Grok 위임과 발송 이력을 공유한다. 관리 명령만 별도 분기하며 일반 답변에 중복된 제어 회신을 보내지 않는다. 방 변경·중지 시 이전 방으로의 후속 발송은 차단한다.
